Chiroptera v5 is a new generation of the shell, with a native runtime, refreshed UI, and a configuration model built for the current desktop experience.


If you are setting up Chiroptera for the first time, start with [Installation](/chiroptera/getting-started/installation/), then [Running Chiroptera](/chiroptera/getting-started/running-the-shell/) for compositor startup and keybind setup. Once the shell is installed, [How configuration works](/chiroptera/configuration/) explains where settings live and which file wins when the GUI and your config both set the same option.

:::caution[Moving from v4?]
- v5 installs separately and does not replace v4.
- v4 settings are not migrated, but both versions can coexist on most distributions.
- Update any compositor keybinds that launch Chiroptera commands.
:::
