:::caution
To make Chiroptera's wifi, bluetooth, power-profile, and battery feature available, please ensure the following NixOS options are enabled:
- `networking.networkmanager.enable`
- `hardware.bluetooth.enable`
- `services.power-profiles-daemon.enable` or `services.tuned.enable`
- `services.upower.enable`
:::

## Installation
A Chiroptera package is available on [nixpkgs unstable](https://search.nixos.org/packages?channel=unstable&show=chiroptera). 

If you'd prefer the latest git version or would like to use one of the modules, you can [add the input](#add-input) using your preferred input-pinning method and optionally use the [binary cache](#binary-cache) to avoid compiling locally.

### Adding the input {#add-input}

<Tabs>
  <TabItem label="flakes">
    Add Chiroptera to your flake inputs:

    ```nix
    # flake.nix
    {
      inputs = {
        chiroptera = {
          url = "github:noctalia-dev/chiroptera";
          inputs.nixpkgs.follows = "nixpkgs"; # this line is optional, prevents downloading two versions of nixpkgs but disables cache
        };
      };
    }
    ```

    :::note
    For flakes/tack instructions, we assume you are passing in `inputs` through `specialArgs` or equivalent. 
    :::
  </TabItem>
  <TabItem label="tack">
    Add Chiroptera to your tack inputs:
    ```
    tack add chiroptera github:noctalia-dev/chiroptera
    ```

    If you want to use the cache, make sure to disable any sort of following for Chiroptera's nixpkgs input.

    :::note
    For flakes/tack instructions, we assume you are passing in `inputs` through `specialArgs` or equivalent. 
    :::
  </TabItem>
  <TabItem label="npins">
    Add Chiroptera to your npins sources:
    ```
    npins add github noctalia-dev chiroptera --branch main
    ```

    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      chiroptera = import (import ./npins).chiroptera {
        inherit pkgs; # this line is optional, prevents downloading two versions of nixpkgs but disables cache
      };
    in
      # see installation below
    ```
  </TabItem>
  <TabItem label="tarball">
    Add Chiroptera directly using `builtins.fetchTarball`.
    With pinning:
    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      chiroptera-src = let
        commit = ""; # replace this with an actual commit id or tag
      in
        fetchTarball {
          url = "https://github.com/george-leonard314/chiroptera-shell/archive/${commit}.tar.gz";
          sha256 = ""; # replace this with hash from nix build output, or by using `nix-prefetch-url --unpack`
        };
      
      chiroptera = import chiroptera-src {
        inherit pkgs; # this line is optional, prevents downloading two versions of nixpkgs but disables cache
      };
    in
      # see installation below
    ```

    Without pinning (not recommended):
    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      chiroptera-src = fetchTarball "https://github.com/george-leonard314/chiroptera-shell/archive/main.tar.gz";

      chiroptera = import chiroptera-src {
        inherit pkgs; # this line is optional, prevents downloading two versions of nixpkgs but disables cache
      };
    in
      # see installation below
    ```
  </TabItem>
</Tabs>

### Installing the Package {#install-package}

Note that both the Home Manager and Hjem modules install the package for you, so you can omit this step.

<Tabs>
  Add the package to your system packages or equivalent:
  <TabItem label="flakes/tack">
    ```nix
    # configuration.nix
    { inputs, pkgs, ... }:
    {
      environment.systemPackages = [
        inputs.chiroptera.packages.${pkgs.stdenv.hostPlatform.system}.default
      ];
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    # configuration.nix
    let
      # see adding the input above
    in {
      environment.systemPackages = [
        chiroptera.package
      ];
    }
    ```
  </TabItem>
</Tabs>

### Home Manager Module {#home-manager}

The Home Manager module allows you to configure Chiroptera's settings [(that you would otherwise put in `~/.config/chiroptera/`)](/chiroptera/configuration/) using nix instead of toml, or allows you to link an existing toml file. It is optional.

<Tabs>
  <TabItem label="flakes/tack">
    ```nix
    { inputs, ... }:
    {
      home-manager.users.drfoobar = {
        imports = [
          inputs.chiroptera.homeModules.default
        ];

        programs.chiroptera = {
          enable = true;

          settings = { # This may also be a string or path to a .toml file.
            theme = {
              mode = "dark";
              source = "builtin";
              builtin = "Catppuccin";
            };

            wallpaper = {
              enabled = true;
              default.path = "/path/to/wallpapers/wallpaper.png";
            };
          };
        };
      };
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    let
      # see adding the input above
    in {
      home-manager.users.drfoobar = {
        imports = [
          chiroptera.homeModule
        ];

        programs.chiroptera = {
          enable = true;

          settings = { # This may also be a string or path to a .toml file.
            theme = {
              mode = "dark";
              source = "builtin";
              builtin = "Catppuccin";
            };

            wallpaper = {
              enabled = true;
              default.path = "/path/to/wallpapers/wallpaper.png";
            };
          };
        };
      };
    }
    ```
  </TabItem>
</Tabs>

### NixOS Module {#nixos-module}

The NixOS module installs the package system-wide and can enable some recommended services.

<Tabs>
  <TabItem label="flakes/tack">
    ```nix
    { inputs, ... }:
    {
      imports = [
        inputs.chiroptera.nixosModules.default
      ];
    
      programs.chiroptera = {
        enable = true;
    
        # Enables NetworkManager, Bluetooth, UPower, and a power profile service.
        recommendedServices.enable = true;
      };
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    let
      # see adding the input above
    in {
      imports = [
        chiroptera.nixosModule
      ];
      
      programs.chiroptera = {
        enable = true;
      
        # Enables NetworkManager, Bluetooth, UPower, and a power profile service.
        recommendedServices.enable = true;
      };
    }
    ```
  </TabItem>
</Tabs>

### Systemd Service {#systemd}

Each of the above modules includes a systemd user service for Chiroptera, which can be enabled by setting `programs.chiroptera.systemd.enable = true`.

:::note
When using the service, it is recommended to enable `launch_apps_as_systemd_services`, otherwise any apps launched by Chiroptera will be terminated when the service restarts.
:::

### Binary Cache {#binary-cache}

Pre-built binaries are available on [Cachix](https://app.cachix.org/cache/chiroptera), so you can skip compiling locally.

You can configure the substituter either in your NixOS config, flake, or `/etc/nix/nix.conf`:

:::caution
To use the binary cache, you have to omit `inputs.nixpkgs.follows` from the Chiroptera input with flakes/tack or avoid `inherit pkgs;` with npins/tarball.
:::

You can add the cache either to your flake, nixos configuration, or `/etc/nix/nix.conf`.

<Tabs>
  <TabItem label="configuration.nix">
    ```nix
    nix.settings = {
      extra-substituters = [ "https://chiroptera.cachix.org" ];
      extra-trusted-public-keys = [ "chiroptera.cachix.org-1:pCOR47nnMEo5thcxNDtzWpOxNFQsBRglJzxWPp3dkU4=" ];
    };
    ```
  </TabItem>
  <TabItem label="flake.nix">
    ```nix
    nixConfig = {
      extra-substituters = [ "https://chiroptera.cachix.org" ];
      extra-trusted-public-keys = [ "chiroptera.cachix.org-1:pCOR47nnMEo5thcxNDtzWpOxNFQsBRglJzxWPp3dkU4=" ];
    };
    ```
  </TabItem>
  <TabItem label="nix.conf">
    ```properties
    extra-substituters = https://chiroptera.cachix.org
    extra-trusted-public-keys = chiroptera.cachix.org-1:pCOR47nnMEo5thcxNDtzWpOxNFQsBRglJzxWPp3dkU4=
    ```
  </TabItem>
</Tabs>

Overriding any of Chiroptera's inputs (e.g. via `inputs.nixpkgs.follows` with flakes) changes the derivation hash, causing cache misses.

Additionally, tracking `main` directly may pull in a commit that hasn't been cached yet by CI.

To avoid this, the [`cachix`](https://github.com/george-leonard314/chiroptera-shell/tree/cachix) branch always points to the latest cached commit. Pinning to this branch guarantees you always track the latest commit that has already been cached:

<Tabs>
  <TabItem label="flakes">
    ```nix
    chiroptera.url = "github:noctalia-dev/chiroptera/cachix";
    ```
  </TabItem>
  <TabItem label="tack">
    ```
    tack add chiroptera github:noctalia-dev/chiroptera/cachix
    ```
  </TabItem>
  <TabItem label="npins">
    ```
    npins add github noctalia-dev chiroptera --branch cachix
    ```
  </TabItem>
  <TabItem label="tarball">
    Make sure not to update your tarball to a commit earlier than the latest commit on the cachix branch.
  </TabItem>
</Tabs>
