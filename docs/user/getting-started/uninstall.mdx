If you wish to remove Chiroptera from your system, you can uninstall the `chiroptera` or `chiroptera-git` package using your distribution's package manager.

### Manual Installation

If you installed manually using `just install release`, remove the files installed under your prefix:

```bash
rm ~/.local/bin/chiroptera
rm -rf ~/.local/share/chiroptera
```

## Cleaning Up

After removing the package, you may want to remove the configuration and cache files.

### Configuration and Cache

Chiroptera stores its configuration and cache in the standard XDG directories. To remove them:

```bash
rm -rf ~/.local/state/chiroptera
rm -rf ~/.cache/chiroptera
```

### Generated Templates

If you enabled any templates in the **Color Scheme** settings, you will need to manually delete the generated files.
