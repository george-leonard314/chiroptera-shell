Visual Studio Code can be themed using the ChiropteraTheme extension, which syncs with Chiroptera's color scheme.

## Setup

1. **Install the ChiropteraTheme extension:**
  - Open VSCode
  - Go to the Extensions view (Ctrl+Shift+X or Cmd+Shift+X)
  - Search for **"ChiropteraTheme"**
  - Click **Install** from the marketplace

2. **Enable VSCode theming in Chiroptera:**
  - Open **Settings → Color Scheme → Templates**
  - Toggle on **VSCode**

3. **Select the theme in VSCode:**
  - Open Command Palette (Ctrl+Shift+P or Cmd+Shift+P)
  - Type "Preferences: Color Theme"
  - Select **ChiropteraTheme**


## How It Works

The extension reads the color scheme generated by Chiroptera's color schemes integration. When you change color schemes in Chiroptera, the theme in VSCode will automatically update to match.

## Troubleshooting

- **Theme not appearing:** Make sure you've installed the "ChiropteraTheme" extension from the VSCode marketplace
- **Colors not updating:** The theme should update automatically when Chiroptera generates new colors. If it doesn't, try:
 - Reloading the VSCode window (Ctrl+Shift+P → "Developer: Reload Window")
 - Switching to a different theme and back to ChiropteraTheme
- **Theme looks broken:** Ensure you have the latest version of the extension and that Chiroptera's templates are generating correctly

## Additional Notes

ChiropteraTheme integrates directly with Chiroptera's color scheme system, providing a seamless theming experience across your desktop and code editor. The theme supports both dark and light modes based on your Chiroptera color scheme settings.
